# Dado em Foco — v1 design

Status: proposed · 2026-10-19

## What

A public-good site for Brazilians (PT-BR only): curated charts of Brazil data
from 2002 to the latest release. Read-only — charts, a one-line description,
the source, and a CSV download per chart. Neutral project; no personal
identity on the site.

## Non-goals (v1)

- No SQL/AI query interface, no free-form explorer.
- No English version.
- No database, no backend, no scheduled refresh.
- No international comparison except COVID.
- No individual names in corruption content.
- No "total money stolen" figure.

## Data

Granularity: national + state (UF). Monthly or quarterly where it exists,
annual otherwise. Every chart labels its frequency.

### Corrupção medida

- **CPI** — Transparency International score per year (Brazil only).
- **CGU** — sanctioned companies (CEIS/CNEP) and expelled public servants
  (CEAF), per year and per UF. Needs a Portal da Transparência API key.
- **Valores recuperados** — CGU leniency agreements, TCU *débitos imputados*.
- **Timeline of cases** — dated markers (Mensalão 2005, Lava Jato 2014, …)
  overlaid on other charts. Each case: operation/name, date, investigating
  institution, *valor envolvido*, current legal status. Operations and
  institutions only — no individuals.

### COVID (2020–2023)

- Deaths per 100k by UF, monthly — Ministério da Saúde.
- Excess deaths vs expected — Portal da Transparência do Registro Civil.
- Vaccination coverage by UF — Ministério da Saúde.
- International, per million (Our World in Data, frozen dataset): Brasil vs
  EUA, Índia, Rússia, Indonésia, México, Argentina, Cuba, Colômbia, Chile,
  Venezuela. Cuba and Venezuela carry the note *"dado oficial, possivelmente
  subnotificado"*; missing excess-death data is shown as missing, never
  imputed.

## Data rules

1. Curated, well-known sources only (list above + OWID, TI).
2. **Every number shows its source, always** — on the chart and in the CSV.
3. Timeline amounts: official body first (MPF, PF, TCU, CGU, court ruling,
   company filing); otherwise a major newspaper labelled *"estimativa da
   imprensa"*; disagreeing sources → show the range. Each amount links to its
   source.
4. Late-starting or broken series: shown from where they start, break marked
   on the chart.
5. Money: default *R$ de hoje*, deflated by IPCA to the latest available
   month (labelled, e.g. "em R$ de set/2026"); toggle to *R$ da época*. CSVs
   carry both columns.

## Presidential terms on every time chart

- Every chart with a time axis draws a dotted vertical line at the start
  (posse) of each presidential term in range, labelled with the name:
  Lula (2003), Lula 2 (2007), Dilma (2011), Dilma 2 (2015), Temer
  (05/2016), Bolsonaro (2019), Lula 3 (2023). Re-elections get their own
  line.
- Temer is labelled as a vice who took office when Dilma was suspended
  (12/05/2016), not as elected.
- One neutral color for every president: no party colors, no shading of
  "good" or "bad" periods. Corruption-case markers use a different style
  (red dashed, label at the bottom) so the two never read as one thing.
- On by default; a global "Mandatos presidenciais" toggle in the header
  hides them. Charts with no time axis (e.g. the state ranking) don't get
  them.
- The term list is hand-curated in `data/mandatos.csv` (start date, name,
  how they took office, source: Presidência da República).
- A line on a monthly axis is drawn at the posse month; on a quarterly axis
  at that quarter; on an annual axis at that year.

## Site

- One page per theme: Economia, Preços, Dinheiro, Trabalho, Contas públicas,
  Corrupção, Sociedade, COVID.
- **Seu estado**: a select that highlights one UF across every state chart,
  persisted in the URL (`?uf=SC`) so it can be shared.
- Per chart: title, one-line description, source link, frequency, CSV
  download.

## Build

- `scripts/refresh.py` — run by hand. Pulls every source into
  `data/<serie>.csv` (tidy: `date, geo, value, value_real?, source, note`).
  Committed to the repo; the CSVs are the open dataset.
- Static site: Astro with React islands, **shadcn/ui** components and
  shadcn charts (Recharts), reading the CSVs at build time. Chart animation
  off, so every chart is complete on first paint. Prototype:
  branch `prototype/ui` (not pushed).
- Hosting: GitHub Pages (`free-brazil.github.io/dadoemfoco`), deployed by a
  GitHub Action on push to `main`. R$0/month.
- Timeline cases live in a hand-curated `data/casos.csv` (one row per case,
  source URL required — the build fails on a row without one).

## Privacy & secrets

- Org `free-brazil`, membership private; no personal name on site or README.
- Commits authored as `Dado em Foco`; pushes from a machine account (see
  open question) so the public event log doesn't show a personal account.
- `TRANSPARENCIA_API_KEY` only in local `.env` (gitignored; `.env.example`
  documents it). Secret scanning + push protection enabled on the repo.
- Nothing from other repos or personal files.

## Implementation notes (2026-10-19)

What changed while building, and why:

- **Gross public debt dropped.** The Banco Central API rejects automated requests from the dev
  machine and from GitHub runners; the IMF copy on IPEADATA has inconsistent values.
- **CAGED by state starts in 2020.** The old CAGED by state isn't in any curated machine-readable
  source; the national series covers 2002+ with the 2020 break marked.
- **CGU sanctions are a snapshot**, not a yearly series: the registry only keeps sanctions in force.
- **Leniency agreements** shown as CGU's headline totals; TCU debt orders left out (owed ≠ recovered).
- **Infant mortality** computed from SIM/SINASC; undercounts where registration was incomplete.
- **Excess deaths by state** from SIM vs the 2015–2019 average (Registro Civil coverage was unstable
  before 2018, so it can't serve as a baseline).
- **Case markers are off by default** (toggle in the header, `?casos=1`); with eight cases they crowd
  every chart. Presidential terms stay on.
- **Astro 7** (needs Node ≥ 22.22): Astro 5 has unpatched advisories, including a critical one.
- **Refresh** also runs on GitHub (`refresh` workflow); commits there come from github-actions[bot].
